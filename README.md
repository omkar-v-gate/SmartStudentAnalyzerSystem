# 🎓 Smart Student Analyzer System

## 📌 Description
Smart Student Analyzer System is a console-based Core Java project that analyzes student marks and learning behavior.  
The system calculates total marks, average, grade, identifies weak subjects, and provides performance improvement tips.

## ✨ Features
- Accept Student Name and ID
- Enter Multiple Subject Marks
- Validate Marks (0–100)
- Calculate Total and Average Marks
- Generate Grade Automatically
- Identify Risk Subjects
- Analyze Learning Behavior
- Provide Performance Tips

## 🛠 Tech Stack
- Core Java
- OOP Concepts
- ArrayList (Collections)
- Loops and Conditional Statements
- Exception Handling
- Eclipse IDE

## ▶️ How to Run
1. Open project in Eclipse  
2. Run the main class  
3. Enter student details  
4. Enter subject marks  
5. View student report and analysis
