# 🎓 Smart Student Learning Behavior Analyzer System

## 📌 Description
A console-based Core Java project that analyzes student academic performance and learning behavior.  
The system calculates total marks, average, grade, identifies weak subjects, and provides performance improvement tips.

## ✨ Features
- Accept Student Details
- Enter Multiple Subject Marks
- Calculate Total and Average Marks
- Automatic Grade Generation
- Behavior Analysis
- Identify Risk Subjects
- Generate Performance Tips

## 🛠 Tech Stack
- Core Java
- ArrayList (Collections)
- OOP Concepts
- Conditional Statements
- Exception Handling
- Eclipse IDE

## ▶️ How to Run
1. Open project in Eclipse  
2. Run main class  
3. Enter student details and marks  
4. View generated report
